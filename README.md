# Haify

A Spotify WebAPI client for Haiku.

Spotify meets the year 2000. This is a little homage to my all-time favorite audio player.
<img width="1276" height="796" alt="grafik" src="https://github.com/user-attachments/assets/91c82401-d3b6-4456-9d52-1680fc080dc6" />


To play with it, install nlohman_json from HaikuDepot.

git clone https://github.com/m199/Haify

make

A recipe for Haikuports and a full Readme is coming soon.
For local playback librespot is needed.
